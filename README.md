# SearXNG Dark Theme

A polished dark theme for [SearXNG](https://github.com/searxng/searxng) — privacy-respecting metasearch engine.

## Requirements

- [Stylus](https://add0n.com/stylus.html) browser extension
  - [Firefox / Zen](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)
  - [Chrome / Brave](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)

## Install

1. Install Stylus from the link above
2. Open Stylus → **Manage** → **Write new style**
3. Copy the contents of [`searxng.user.css`](searxng.user.css)
4. Paste into the editor
5. Set **Applies to** → `URL starting with` → `SearXNG URL`
6. Save

## Features

- Clean dark mode with card-style results
- Circular favicons with subtle borders
- Floating pill category tabs
- Hidden clutter (footer, duplicate infoboxes, thumbnails in text results)
- Smooth hover animations
